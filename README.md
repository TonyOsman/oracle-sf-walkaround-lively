Lively Wallpaper package.

## Usage

The wallpaper is a small canvas walkaround scene with click-to-move and keyboard movement. It uses a stylized Oracle/Redwood/San Francisco waterfront setting and avoids recreating the Oracle logo.

Import the generated zip into Lively Wallpaper.
